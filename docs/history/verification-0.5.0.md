# 0.5.0 验证记录

日期：2026-11-07 至 11-08。范围：Windows 原生发送端与一键配置、原生接收端在目标 NAS 上的低延迟配置、诊断与稳定性修复。

## 本机自动化测试

- 176 项 Linux 单元测试通过（WSL Docker，镜像 `lan-audio-bridge:0.5.0`）。
- 原生后端集成：真实 VBAN PCM、四手机总线、12 种切换、混音满幅峰值 32759/32767、增益隔离、空闲/唤醒、丢包与重排恢复、接收进程故障恢复，全部通过。
- Python 桌面后端与纯手机模式集成（路由、DLNA、PulseAudio 启动、SIGTERM 重启）通过。
- 原生接收端，2.67 ms 突发，10/3 ms，±200 ppm，120 秒严格测试：P95 7.6–8.8 ms，零欠载；保持唤醒与延迟挂起检查通过。
- 空闲时运行时启动的 `pactl` 从约 20 次/秒降到 0.6–0.7 次/秒。
- Windows 配置脚本 33 项检查通过（Windows PowerShell 5.1；本机未安装 PowerShell 7）。发送端以 MSVC `/W4 /WX` 编译通过。

## 目标设备实测

- Windows 段（128 帧引擎、低延迟播放器）：中位数 2.7 ms，P95 5.4 ms。
- NAS 输出：中断调度 96 帧 × 3；Pulse I/O 线程 SCHED_RR，接收端 SCHED_FIFO；ALSA 延迟 9–12 ms。
- 声学端到端稳态约 54–61 ms，会话开头约高 15 ms 并持续约 15 秒；详见[延迟验证](../latency.md)。
- 实际安装：主输出“NAS 音频”（HDMI，Microsoft HD Audio 驱动）、备用“NAS 音频（备用）”（Realtek USB，Microsoft USB Audio 2.0 驱动）；显示器休眠时自动切换并切回；切到其他输出时发送端待机；Voicemeeter 端点已隐藏，默认麦克风改为真实设备。

## 已知边界

- DAC 之后的约 30–35 ms（光纤接收、扬声器处理、空气传播）未分离测量。
- 带 20 ms 设备下限的 sink 测试需要 `gcc`，运行镜像中没有，本轮未执行。
- NAS 端只做了只读检查；IRQ 分配等主机设置未修改。
